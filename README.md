# PetMatch

A single-page lifestyle quiz that recommends dog, cat, rabbit, small-rodent,
and bird types based on your home and habits. Built from `pet-match-spec_1.md`.

**This is general lifestyle guidance, not veterinary or behavioral advice.**

## Quick start

```bash
npm install
npm run dev
```

Open http://localhost:3000. That's it — no API keys, no environment
variables, no backend to configure. The whole app is static files; `npm run
dev` just runs a tiny local server so `data/pets.json` loads without
tripping browser CORS restrictions on `file://` URLs.

## About the shelter-search feature (spec section 6)

The original spec called for embedding live Petfinder listings via a
backend OAuth proxy. **Petfinder shut down its public developer API on
December 2, 2025** — they now only offer a WordPress widget, which isn't
usable from a custom app like this one. That backend (`api/animals.js`,
`lib/petfinder.js`) has been removed; there was nothing left for it to call.

"See adoptable near me" now opens real, live search results directly on
Petfinder's and Adopt-a-Pet's own websites in a new tab, pre-filled with
your location where possible (`js/shelterSearch.js`). No API key, no
backend, no secret to protect, nothing that can crash on deploy.

If this project ever needs embedded results again,
[RescueGroups.org](https://rescuegroups.org/services/adoptable-pet-data-api/)
offers a free API covering similar ground (adoptable animals + shelter/rescue
data, radius search) with a simpler API-key auth model than Petfinder's OAuth
— that would be the natural next backend to build against.

## How it's built (maps to the spec's sections)

| Spec section | What's here |
|---|---|
| 3. Dataset | `data/pets.json` — 50 entries (20 dogs, 15 cats, 5 rabbit breeds, 5 rodent types, 5 bird species), generated by `scripts/generate_pets.py`. The spec assumed this file would be supplied alongside it; it wasn't attached, so it was built fresh against the same schema. |
| 4. Quiz | `js/quiz-questions.js` (13 questions, data-driven) + `js/app.js` (step navigation, progress bar, in-memory state). |
| 5. Matching algorithm | `js/matching.js`. See "Matching weights" below — the spec asked for a weighted model but didn't specify weights, so they're spelled out and documented here rather than buried as magic numbers. |
| 6. Shelter search | `js/shelterSearch.js` — see above; this is the one part of the spec that changed shape after Petfinder's API shutdown. |
| 7. Tech stack | Plain HTML/CSS/JS, no build step, no backend at all. `server.js` is just a static file server for local dev convenience. |

## Matching weights (spec's open question)

Section 5 said "simple weighted-scoring model" without saying what the
weights should be. Here's what this build uses, out of 100 points total:

- Energy/exercise fit — 15
- Alone-time tolerance — 12
- Owner experience level — 12
- Allergies — 12 (a "significant allergies + not hypoallergenic" hard
  mismatch zeroes out *this factor only*, not the whole score, per spec)
- Living space / apartment fit — 10
- Noise tolerance — 10
- Grooming tolerance — 8
- Budget — 8
- Kids / other pets in household — 8
- Stated goals (companionship, exercise buddy, etc.) — 5

These are a first-pass judgment call, not something derived from user
testing — they're the kind of thing worth a second opinion.

## Known limitations / next steps

- **Climate preference isn't wired into scoring yet.** The quiz collects it
  and the dataset has a `climatePreference` field, but there's no scoring
  factor for it — it's currently a no-op.
- **Shelter search is link-out, not embedded**, because Petfinder's API is
  gone (see above). Embedding real listings again would mean building
  against RescueGroups.org or a similar API instead.
- **Weights are a first pass**, not validated against real users yet.
- **Not yet deployed** in every sense — works locally and is straightforward
  to host as a fully static site (GitHub Pages, Vercel, Netlify, Replit, or
  literally anywhere that serves static files, since there's no backend
  left to configure).

## Project structure

```
index.html            Single-page app shell (landing / quiz / results screens)
css/styles.css        All styling, responsive + light/dark aware
js/matching.js         Weighted scoring engine
js/quiz-questions.js   Quiz question definitions
js/app.js              Screen/quiz navigation, results rendering, adoptable-link UI
js/shelterSearch.js    Builds the Petfinder/Adopt-a-Pet outbound search links
data/pets.json          50-entry breed/type dataset
server.js                Local static file server (dev convenience only)
scripts/generate_pets.py  Script that generated data/pets.json
```
